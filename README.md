# How to Customize the appearance of a Blazor HeatMap Chart using Bubbles


This sample demonstrates how to customize the appearance of the Syncfusion [Blazor HeatMap](https://www.syncfusion.com/blazor-components/blazor-heatmap-chart) component using bubble visualizations. The implementation showcases multiple bubble-rendering modes that allow data values to be represented through color, size, sectors, or a combination of size and color. These visualization techniques help present multidimensional data more effectively and make it easier to identify patterns, trends, and outliers in large datasets.
 
Refer to the following documentation to learn about the Blazor HeatMap Chart component: 
https://help.syncfusion.com/chart-sdk/blazor/heatmap-chart/bubble-heatmap


Check out this online example of the Blazor HeatMap Chart component:
https://blazor.syncfusion.com/demos/heatmap-chart/bubble-types?theme=fluent
https://blazor.syncfusion.com/demos/heatmap-chart/color-and-size-attributes?theme=fluent

## Key Features

- Demonstrates HeatMap bubble visualization using the Syncfusion HeatMap component.
- Shows how to configure bubble-based rendering instead of traditional rectangular HeatMap cells.
- Includes examples for **Color** bubble mode, where values are represented using color variations.
- Includes examples for **Size** bubble mode, where values are represented through bubble dimensions.
- Demonstrates **Sector** bubble visualization for representing values using segmented bubble sectors.
- Shows **SizeAndColor** bubble mode that combines size-based and color-based value representation.
- Provides sample HeatMap data used to render bubble visualizations.
- Illustrates HeatMap appearance customization techniques for advanced data visualization scenarios.
- Demonstrates different Bubble HeatMap configurations available in the Syncfusion HeatMap component.

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file
3. Restore all NuGet packages.
4. Build the solution.
5. Run the application using **Ctrl+F5**.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the directory containing `BlazorApp_HeatMap.csproj`.

```bash
dotnet restore
dotnet run
```

4. Open the local application URL displayed in the terminal output.
